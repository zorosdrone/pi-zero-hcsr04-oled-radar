# HC-SR04 OLED Radar Demo v1.0.0

Raspberry Pi Zero 2 W、HC-SR04系距離センサー、SG90、SSD1306 OLEDによる走査レーダーVer4のデモです。

## 添付ファイル

- `radar-sweep-oled-demo-v1.0.0.mov`: レーダー全体の走査動作とOLED表示
- `radar-oled-display-demo-v1.0.0.mov`: OLEDレーダー表示のクローズアップ

## 注意

- 測距・走査の結果は、センサー、電源、配線、反射物、周囲環境に依存します。
- 配線と電源の安全上の注意は[SAFETY.md](../SAFETY.md)を参照してください。
